What injection is

Every system in this exam trusts its own rule for telling data apart from code. An applicant's name is supposed to stay a name; a search term is supposed to stay a search term. Injection is what happens when that rule was worded imprecisely: an attacker supplies input that the rule accepts as harmless data, but that the underlying engine reads as an instruction. The examiner never notices, because from where they're standing, the vow was never broken.
